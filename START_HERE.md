## 🚀 Getting Started (3 Steps)

### Step 1: Install Node.js (2 minutes)
1. Download from [nodejs.org](https://nodejs.org)
2. Install LTS version
3. Restart computer

### Step 2: Setup Project (2 minutes)
```bash
cd pulang-bersamamu
npm install
```

### Step 3: Run Locally (30 seconds)
```bash
npm run dev
```

**That's it! Your website is running at http://localhost:3000** 🎉

## 📸 Photo Tips

**Best practices:**
- Use high-quality photos (at least 1000px wide)
- Mix portrait and landscape
- Show emotion and connection
- Include close-ups and wide shots
- Clean up metadata if sensitive

**File sizes:**
- JPG: Usually smaller, good for photos
- PNG: Good for graphics/logos
- WebP: Smaller but less compatible
